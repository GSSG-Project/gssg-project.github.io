GSSG: Online Object-Centric Gaussian Splatting Scene Graphs with Multi-Modal Indexing for Scalable Open-Vocabulary Querying

A hierarchical, open-vocabulary 3D scene graph built online on an object-centric 3D Gaussian Splatting map, and made queryable through semantic, spatial, and topological indices.

Author names omitted for anonymous review.

Paper pending Video pending Code

Robots that act on language need a map that is precise, open-vocabulary, efficient to query, and built online. GSSG addresses the two costs that make this hard at scale on a 3DGS map: memory, by spending Gaussians on objects rather than walls and floors and paging out-of-view cells to RAM; and query latency, by decoupling retrieval into three indices. A new task changes the query, not the map.

BEmbedding calibrationtable

Table B1. Embedding calibration. CLIP places image and text embeddings in different regions of the same space (the modality gap [1]), so a text query ranks object embeddings with a systematic offset. The pass removes part of that offset without any training: every object embedding is shifted by the same vector α (μtxt − μimg) and re-normalized, where μimg is the mean object embedding of the map and μtxt is the mean text embedding of the 1000 ImageNet-1K class names [2], a vocabulary independent of the benchmark labels. Only a partial shift helps ranking [3, 4], so α = 0.25 is fixed for both datasets. It raises the synonym score and lowers the incorrect rate; the missing rate is unchanged because no objects are added.

From the paper

Pipeline overviewFig. 2, three components

Object-centric map

An objectness weight w(u) = Mconf(u)γ + β decides where Gaussians are seeded and where the loss is applied. Submapping evicts out-of-view cells to RAM.

Scene graph

Detections match nodes by voxel overlap and CLIP similarity, each gated, then fuse by a confidence-weighted mean. Floors from the height histogram; rooms by watershed over an analytic wall map.

Three indices

Semantic: HNSW [8] over embeddings. Spatial: R-tree [9] over object boxes; near, on, inside, above, below computed on demand. Topological: the floor–room–object hierarchy. Composed by rules, or by an LLM planner for complex instructions.
